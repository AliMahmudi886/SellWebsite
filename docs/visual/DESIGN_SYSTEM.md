# Design system

Global tokens live in src/app/globals.css. Espresso (#35271e) frames the store, paper (#f9f5ed) and sand (#eee4d4) support browsing, fired clay (#813f2b) signals action, and muted text (#66584d) sits on light surfaces. Use the existing Vazirmatn variable font for Persian and Latin interface text, with native fallbacks. Body text is 15px with 1.7 line height. Section titles scale from 25px to 42px. Use fluid 16–64px gutters, 44–100px section spacing and a 1512px desktop container.

Primary actions are filled and links are underlined where they lead to policy or editorial content. Use 44px icon actions, a visible teal focus outline, and compact corners. Product images use a 4:5 card ratio. Cart is the primary elevated dialog. Management headers use the same palette, with borders and dedicated error surfaces. Icons reuse the local UiIcon set.
