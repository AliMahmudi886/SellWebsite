## Version control

When you finish a task that changes project files, review the diff, run relevant checks, and commit the changes you made for that task with a descriptive Git commit message. Stage only the files or hunks that belong to your work. Preserve unrelated local changes and leave secrets, local data, and generated files excluded by Git ignore rules out of commits. If your task makes no committable changes, skip the commit.
